# 1. 조사 개요

익명 투표 SNS 서비스의 실제 운영 데이터를 분석했다.

* **대상:** 익명 투표 SNS 앱 원본 덤프
* **분석 환경:** MySQL Container의 `final` / `hackle` 스키마, SQL 조사
* **서비스 기간:** 2023-03 ~ 2024-05
* **총 가입자:** 677,085명

---

# 2. 발견 1 - 투표 데이터는 10개 학교에서만 확인할 수 있었다

전체 5,951개 학교 중 실제 가입자가 존재하는 학교는 5,551개였다.

다만 원본 데이터에서 투표 관련 정보가 마스킹되지 않아 확인할 수 있었던 학교는 10개뿐이었다. 따라서 투표 활동과 학교별 이용 현황은 이 10개 학교를 중심으로 확인할 수 있었다.

확인 가능한 10개 학교는 모두 학생 수가 많은 상위 학교였고, 이 학교에서는 가입자의 93~99%가 실제 투표 활동까지 이어졌다.

10개 학교의 가입자는 전체 677,085명 중 5,090명으로 **0.75%**에 불과했다. 투표 이용 현황을 전체 서비스로 일반화하기에는 데이터의 범위가 제한되어 있었다.

---

# 3. 발견 2 - 확인 가능한 투표 이용 학교와 매출은 직접 연결되지 않았다

## 3-1. 결제유저 대부분은 투표 데이터를 확인할 수 없었던 학교에 있었다

투표 데이터가 확인 가능한 10개 학교의 결제유저는 410명으로 전체의 **0.69%**였다.

나머지 학교의 결제유저는 58,782명으로 **99.31%**를 차지했다.

확인 가능한 범위에서는 대부분의 결제가 투표 데이터를 확인할 수 있었던 학교가 아닌 다른 학교에서 발생했다.

## 3-2. 매출 역시 투표 데이터가 확인된 학교에 집중되지 않았다

전체 매출 201,341,000원 중 이 10개 학교의 매출은 **1,277,700원(0.64%)**에 그쳤고, 나머지 학교에서 발생한 매출은 **200,063,300원(99.36%)**이었다.

매출 1위 학교인 거창 지역 학교는 공식 학생 수가 278명으로 이 10개 학교에 포함되지 않았다.

나머지 학교의 투표 데이터가 마스킹되어 있었기 때문에, **투표 기능 이용 여부와 매출의 관계를 전체 학교 기준으로 판단할 수는 없었다.**

## 3-3. 결제 전환율 자체는 큰 차이가 없었다

투표 데이터를 확인할 수 있었던 10개 학교에서는 5,090명 중 410명이 결제해 **8.06%**의 전환율을 보였다.

나머지 학교는 671,995명 중 58,782명이 결제해 **8.75%**였다.

결제 전환율만 놓고 보면 두 집단의 차이는 크지 않았다.

다만 투표 데이터를 확인할 수 있었던 10개 학교 안에서는 결제유저의 활동량이 더 높게 나타났다.

| 구분          |   결제유저 |  미결제유저 |
| ----------- | -----: | -----: |
| 평균 질문 세트 완료 |  45.80 |  29.83 |
| 평균 투표 수     | 362.58 | 228.40 |

결제유저는 미결제유저보다 질문 세트를 **53.5%** 더 많이 완료했고, 투표도 **58.7%** 더 많이 했다.

투표 활동과 결제가 직접 연결된다고 보기는 어려웠지만, **투표 데이터를 확인할 수 있었던 학교에서는 결제유저의 활동량이 더 높게 나타났다.**

---

# 4. 발견 3 - 가입자의 63.9%는 일주일 안에 활동이 끊겼다

서비스에는 별도의 로그인 기록이 없어 친구 요청을 보낸 기록을 활동 여부의 기준으로 삼았다.

전체 가입자의 95.9%는 최소 한 번 이상 친구 요청을 보낸 기록이 있었다.

| 활동 기간        |   사용자 수 |    비율 |
| ------------ | ------: | ----: |
| 활동 없음        |  28,013 |  4.1% |
| 가입 당일만 활동    | 192,555 | 28.4% |
| 1~6일 내 활동 종료 | 240,275 | 35.5% |
| 7~29일        | 188,444 | 27.8% |
| 30~89일       |  22,442 |  3.3% |
| 90~179일      |   3,709 |  0.5% |
| 180일 이상      |   1,647 |  0.2% |

가입 당일 또는 1~6일 내 활동을 멈춘 사용자가 전체의 **63.9%**였다. 30일 이상 활동을 이어간 사용자는 **4.1%**에 그쳤다.

### 코호트별 활동 기간

| 가입 월    |     가입자 | 7일 이상 | 30일 이상 |
| ------- | ------: | ----: | -----: |
| 2023-03 |      33 | 57.6% |  54.5% |
| 2023-04 |  19,060 | 45.7% |  10.6% |
| 2023-05 | 635,505 | 32.2% |   3.9% |
| 2023-06 |  16,737 | 14.8% |   3.8% |
| 2023-07 |   1,849 |  9.2% |   3.8% |

전체 가입자의 **93.9%**가 2023년 5월에 한꺼번에 가입했는데, 이 코호트의 30일 이상 활동 비율은 3.9%였다.

반면 초기 가입자는 규모가 작은 대신 30일 이상 활동한 비율이 상대적으로 높았다.

# 5. 발견 4 - 투표는 대부분 완료했지만, 결과를 본 뒤 힌트를 사용하는 경우는 많지 않았다

투표 과정을 5단계로 나누어 확인했다.

| 단계           |     사용자 수 | 이전 단계 대비 |
| ------------ | --------: | -------: |
| 1. 질문 노출     | 1,265,476 |     100% |
| 2. 투표 완료     | 1,218,687 |    96.3% |
| 3. 투표 결과 생성  | 1,217,558 |    99.9% |
| 4. 상대방 결과 확인 |   675,931 |    55.5% |
| 5. 답변 공개(힌트 사용)     |   111,761 |    16.5% |

질문을 본 뒤 실제 투표까지 이어지는 비율은 **96.3%**로 높았다.

줄어든 지점은 결과를 확인한 뒤 답변을 공개하는 단계였다. 결과를 확인한 사용자 중 힌트를 쓴 사용자는 **16.5%**에 불과했다.

투표 결과가 생성된 기록을 다시 답변 여부에 따라 나눠보면 다음과 같았다.

| 상태            |   사용자 수 |    비율 |
| ------------- | ------: | ----: |
| 결과를 확인하지 않음   | 541,627 | 44.5% |
| 확인했지만 답변하지 않음 | 556,305 | 45.7% |

* **44.5%**는 결과를 확인하지 않았고
* **45.7%**는 결과를 확인했지만 힌트 사용으로 이어지지 않았다.

# 6. 탈퇴 이유 - 친구 부족과 콘텐츠 부족이 많았다

탈퇴 기록은 `accounts_userwithdraw` 테이블에서 총 **70,764건**을 확인했다. 전체 가입자의 **10.5%**에 해당한다.

다만 탈퇴 사유 데이터에는 사용자 식별자가 없어 탈퇴 이유를 가입 경로나 활동량, 학교, 결제 여부와 연결해서 확인하기는 어려웠다.

| 탈퇴 이유       |  사용자 수 |    비율 |
| ----------- | -----: | ----: |
| 기타          | 40,301 | 57.0% |
| 같이 할 친구가 없음 | 14,450 | 20.4% |
| 재미있는 질문이 없음 | 13,133 | 18.6% |
| 버그가 많음      |  2,031 |  2.9% |
| 구독료가 비쌈     |    730 |  1.0% |

‘기타’를 제외하고 보면 친구가 없다는 이유가 **20.4%**로 가장 많았고, 재미있는 질문이 없다는 이유가 18.6%로 뒤를 이었다.

반면 버그나 가격을 이유로 탈퇴한 사용자는 상대적으로 적었다.

탈퇴 사유로 확인할 수 있는 범위에서는 기술적인 문제나 가격보다 **함께 사용할 친구가 없거나 콘텐츠가 부족하다는 점이 더 크게 나타났다.**

전체 탈퇴자의 63%가 2023년 5월에 집중되어 있었지만 같은 시기에 전체 가입자의 93.9%가 몰려 있었다. 따라서 5월의 탈퇴 증가 자체를 별도의 이상 현상으로 보기는 어려웠다.

# 7. 종합

이번 분석에서는 서비스의 실제 운영 데이터를 확인하면서 **어떤 데이터를 어디까지 분석할 수 있는지부터 확인할 필요가 있었다.**

투표 관련 데이터는 마스킹되지 않은 10개 학교에서만 확인할 수 있었기 때문에, 투표 이용 현황과 매출의 관계도 해당 학교를 중심으로 살펴볼 수 있었다. 그 범위에서는 투표 활동과 결제가 직접 연결된다고 보기는 어려웠지만, 결제유저의 활동량이 더 높게 나타나는 특징은 확인할 수 있었다.

또한 투표 퍼널에서는 투표 자체보다 결과 확인 이후의 힌트 사용 단계에서 큰 이탈이 나타났고, 탈퇴 사유에서는 친구 부족과 콘텐츠 부족이 주요 이유로 나타났다.

다만 원본 데이터에는 로그인 기록이 없고, 탈퇴 사유에는 사용자 식별자가 없으며, 일부 투표 데이터는 마스킹되어 있었다. 따라서 개별 사용자 행동을 연결해 원인을 검증하거나 서비스 전체의 이용 구조를 충분히 설명하기에는 한계가 있었다.

결국 이번 분석에서 확인한 것은 **서비스의 문제뿐 아니라, 현재 데이터만으로는 무엇을 확인할 수 있고 무엇을 확인하기 어려운지**였다. 이후에는 이 한계를 줄이고 실제 데이터가 쌓일수록 같은 분석을 반복할 수 있도록 데이터 파이프라인을 구축하는 방향으로 이어갔다.
